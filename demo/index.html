// Code block: must NOT be translated during full-page translation
async function translateCurrentPage(targetLang = 'zh-CN') {
  const response = await chrome.runtime.sendMessage({
    type: 'PAGE_TRANSLATE_START',
    payload: { sourceLang: 'auto', targetLang, displayMode: 'bilingual' }
  });
  return response?.status;
}

1. Why Local-First AI Gateways Matter for Browser Assistants

Browser-based reading assistants frequently struggle with fragmented API keys, high latency, and inconsistent prompt engineering across dozens of model providers. Routing page translation and contextual summarization through a unified local gateway on loopback port 4319 decouples the extension UI from provider-specific schemas while keeping user credentials strictly under local host control. When a user switches seamlessly from GLM-4.5 Air for rapid skimming to Kimi K3.1 Pro for deep architectural analysis, the sidebar updates its active routing configuration without discarding conversation history.

Furthermore, disabling verbose chain-of-thought reasoning on latency-sensitive translation batches reduces turnaround time from over sixty seconds to roughly three seconds per viewport batch. Duplicate UI labels and navigation badges are deduplicated within each batch before dispatch, ensuring that repeated status words like timestamps or release tags only incur a single upstream inference call while still updating every visible instance in lockstep.

2. Designing Non-Destructive DOM Reading and Context Extraction

A resilient reading companion must respect both the visual layout of modern web applications and the semantic boundaries of technical documents. In replacement mode, directly mutating leaf text nodes preserves responsive CSS grid columns, inline SVG icons, and tightly aligned timeline rows without injecting wrapper spans that would break flex widths or table borders. Simultaneously, dynamic observers track lazy-loaded dashboard widgets and expandable accordion panels so newly mounted analytics cards translate automatically without forcing the reader to re-trigger full-page translation.

When users invoke page summarization or contextual question answering, structured content extraction gathers document headings alongside main article paragraphs while pruning navigation menus, decorative scripts, and raw code blocks. Combining clean prose extraction with selective citation lets readers move effortlessly from scanning bilingual documentation to synthesizing actionable takeaways, drafting follow-up emails, and refining technical notes directly within the browser viewport.
